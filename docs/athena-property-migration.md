# 雅典娜旧版属性盘点与迁移

来源：`D:/Dota Addons/athena-reborn`，提交 `5a058ffbe2936df69ddd6b7f707e8ac1bbf20e01`。本目录 JSON 保存逐项映射；运行时只从 `properties.kv` 生成映射，不读取旧项目。

## 范围与职责

- 97 个 modifier 属性声明、67 个永久属性常量、75 个已登记装备字段，另有 2 个未登记装备引用。
- 基础生命/魔法/攻击/护甲/暴击/三围/成长/回复/攻击间隔/距离/分裂仅由 `modifiers/framework/modifier_common.ts` 从 KV 初始化。
- `framework/property_system/athena_properties.ts` 保留旧版取整、三围派生、基础与额外乘区，以及物理/魔法暴击区分。
- `framework/unit_attributes.ts` 管理永久与装备来源、升级、攻击/击杀与时间成长、任务属性奖励、结算停止和跨局清理，通过 CModule/Event 接入。
- 原有 C1 字段和枚举顺序保留；补充属性追加，避免原字段编号变化。

## 已接入的计算

- 三围：原始值及等级成长分别取整，永久基础与基础百分比、装备额外与总百分比分层。攻击派生为力量×2 + 敏捷×3 + 智力；生命为力量×20，魔法为智力×12。
- 回复：力量×0.16 生命/秒，智力×0.08 魔法/秒；固定回复与最大值百分比回复保留。普通单位使用引擎回复，大数值生命使用逻辑代理回复。
- 战斗：物理护甲系数 0.06，魔法固定 25% 抗性，百分比减免后扣固定格挡；物理与魔法暴击覆盖相应类型的攻击和技能；吸血、分裂均经过实际伤害入口。
- 装备：只聚合 0—5 装备栏，排除法宝；吞噬列表可由后续玩法调用 `UnitAttributes.RefreshItems(hero, devouredItems)` 提供，后续刷新保留该列表。按旧版逐字段 SUM/MULTIPLY/DECMUL 聚合，卸装只释放装备来源。
- 生命周期：每秒与每分钟成长仅在本局战斗运行；升级额外成长按等级差结算；死亡双上报去重；玩家级来源按 playerID 注册，并在旧实体已销毁时仍能清除。

## 原版异常与保留边界

- “敏捷格挡”实际读取力量×0.2，沿用有效代码。
- 力量“减伤”在旧版返回正的 incoming 百分比，本次保留该符号与 60% 上限。
- 击杀力量实际写入击杀攻击值，`KILL_STRENGTH` 数值未生效，沿用有效代码。
- 永久 MANA 没有消费；永久 ARMOR_PER_MIN 没有消费；部分三围/击杀成长常量未登记；均保留定义，不自动启用。
- 攻击减甲调用被原版注释；钓鱼/挖宝暴击原版注明未实现；未借迁移新增这些玩法。
- 装备 `item_attack_damage_percent` 与 `item_kill_soul` 被代码引用但未登记，旧版恒为零；没有加入自动装备聚合。
- 收益类属性已定义并可查询，经验增益已接入引擎，永久属性收益加成已接入成长。完整掉落、击杀基础奖励、魂晶/荣耀账户、钓鱼/挖宝、吞噬玩法和旧英雄/装备技能脚本不属于属性框架，仍由相应玩法移植时消费这些字段。
- 旧版属性面板尚未移植；客户端已有 PropertySystem 网表字段与本地化，不代表旧版 HUD 已完成。

## 使用与生成

新 modifier 使用 `StaticProperty()` / `DynamicProperty()` 返回 `PropertyFunction`，不恢复旧 EDeclareFunctions 存储。旧字段可查自动生成的 `ATHENA_MODIFIER_PROPERTIES`、`ATHENA_PERMANENT_PROPERTIES` 和 `ATHENA_ITEM_PROPERTIES`。

```ts
hero.AddPermanentAttribute("CUSTOM_ATTRIBUTE_STRENGTH", 10);
hero.AddPermanentAttribute("CUSTOM_ATTRIBUTE_ATTACK", 5, true); // 受玩家属性收益加成
const strength = GetStrength(hero);
```

修改 `properties.kv` 后执行 `npm.cmd run generate:properties -- --no-editor-reload`，再执行 `node node_scripts/build-vscripts.js`。`legacy_item_aggregation` 保留装备预聚合规则，不能用目标字段的聚合规则替代。

Panorama 共享属性/枚举/常量已编译为 polyfill；完整严格 UI 构建受当前缺失的 247 张图片（445 处引用）阻止，缺图清单在 `node_modules/.cache/panorama/missing-images.json`。这不等于完整 UI 构建通过。

Dota VConsole 端口 29000 未连接，本轮没有游戏内实测；双玩家隔离与跨局行为目前属于本地生产代码测试证据。
